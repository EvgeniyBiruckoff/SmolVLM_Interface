# SmolVLM

Интерфейс для SmolVLM

# Сборка образа
docker build -t smolvlm .

# Запуск контейнера
docker run -p 8000:8000 -it --rm smolvlm

# Настройки

В Dockerfile можно настроить:

    NN_VER - версия модели: 256M или 500M

    DEVICE - устройство: cuda или cpu

Важно: Если CUDA недоступна, система автоматически переключится на CPU.

После запуска приложение доступно по адресу: http://0.0.0.0:8000
