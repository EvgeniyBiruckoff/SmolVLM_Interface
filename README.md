# SmolVLM

Интерфейс для SmolVLM

# Сборка образа
docker build -t smolvlm .

# Запуск контейнера
С поддержкой видеокарты: docker run -p 8000:8000 -it --rm --gpus all -v $(pwd)/data:/app/data smolvlm
Без поддержки видеокарты: docker run -p 8000:8000 -it --rm -v $(pwd)/data:/app/data smolvlm

# Настройки
В Dockerfile можно настроить:

    NN_VER - версия модели: 256M или 500M

    DEVICE - устройство: cuda или cpu

Важно: Если CUDA недоступна, система автоматически переключится на CPU.

# UPDATE
Добавлена возможность загружать картинки с диска, для этого достаточно написать абсолютный путь изображения
Обратите внимание, что это абсолютный путь в контейнере. Для добавления картинок в контейнер была смонтирована папка smolvlm/data в app/data.


После запуска приложение доступно по адресу: http://0.0.0.0:8000
